# T1 / T2 / Pipeline 使用说明

## 组件与文件

- `T1_parser/pseudocode_parser.py`：解析伪代码，生成内存流程语义。
- `T1_parser/sample.py`、`use_parser.py`、`test_pseudocode_parser.py`：T1 示例、调试和测试。
- `T2_workflowgraph/workflow_graph_builder.py`：生成 Dify 节点、边、结构化输出、布局和 end 节点。
- `T2_workflowgraph/build_sample_graph.py`、`test_workflow_graph_builder.py`：单独运行和测试 T2。
- `Pipeline/pipeline.py`：在内存中串联 T1/T2，输出并回读校验 `workflow.graph` JSON。
- `Pipeline/dify_import_config.json`：仅本机使用的 Dify 导入配置，包含目标 App 和 token。
- `Pipeline/dify_import_config.example.json`：不包含 token 的配置模板。
- `import_graph_to_dify.py`：备份并覆盖目标应用 draft，使 graph 显示到 Studio 画布。

## 第一步：生成 workflow.graph

在项目根目录运行：

```powershell
python Pipeline\pipeline.py T1_parser\sample.py `
  --provider "langgenius/deepseek/deepseek" `
  --model "deepseek-chat" `
  --output workflow_graphs\sample_graph.json
```

Pipeline 会在写入后自动回读并检查 JSON、`nodes`、`edges` 和 `viewport`，因此不需要再运行
`python -m json.tool`。生成失败时命令会直接报错，不会进入导入步骤。

## 第二步：自动导入 Dify

首次使用时，从公开模板复制一份本机私有配置：

```powershell
Copy-Item Pipeline\dify_import_config.example.json Pipeline\dify_import_config.json
```

然后打开 `Pipeline/dify_import_config.json`，配置一次即可：

```json
{
  "base_url": "http://localhost",
  "app_id": "a120896d-0344-48f0-9eda-27439a58d6a2",
  "graph": "workflow_graphs/sample_graph.json",
  "backup_dir": "workflow_graphs/backups",
  "access_token": "在这里粘贴 Cookies 中复制的 access_token",
  "auto_confirm": true
}
```

token 填在 `access_token` 后面的双引号中，只填写 token 本身。配置文件已被根目录
`.gitignore` 忽略，不会被 Git 提交，但它仍是本机明文凭据，请勿发送给别人。HTTPS 环境的
Cookie 名可能是 `__Host-access_token`。token 登录过期后，只需重新复制并替换这一项。

配置完成后运行：

```powershell
python import_graph_to_dify.py
```

当 `auto_confirm` 为 `true` 时，一次命令会依次读取旧画布、保存完整备份、导入新 graph，
再从 Dify 回读验证。备份保存在 `workflow_graphs/backups/`，不需要先执行 `--dry-run`。

如只想验证连接并备份、不修改画布，可选运行：

```powershell
python import_graph_to_dify.py --dry-run
```

导入成功后刷新：

`http://localhost/app/a120896d-0344-48f0-9eda-27439a58d6a2/workflow`

## 测试

修改代码后运行：

```powershell
python -m pytest T1_parser\test_pseudocode_parser.py `
  T2_workflowgraph\test_workflow_graph_builder.py `
  Pipeline\test_pipeline.py Pipeline\test_import_graph_to_dify.py `
  -q -p no:cacheprovider
```

日常生成和导入不必每次运行全部测试；Pipeline 和导入器会校验本次输入及保存结果。
